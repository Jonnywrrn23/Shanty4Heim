# Sea Shanty 2 Sailing Mod

Plays the iconic Sea Shanty 2 from RuneScape when you dance on a boat in Valheim!

## Installation

Install with r2modman or manually place in BepInEx/plugins/

## Usage

1. Get on any boat
2. Use the dance emote
3. Enjoy the tunes!

Everyone nearby hears it, not just the dancer. Dancing is the only emote that
starts it - sitting, waving and the rest are left alone.

## Level-up sound

Gaining a level in any skill plays a short jingle. Only you hear it: it is not a
world sound, so nobody else on the server has to share your woodcutting. Turn it
off in the settings below if it wears thin.

## Configuration

Settings > Audio has both of these, directly under Music:

- **Shanty4Heim Sound** - volume slider. It takes effect as you drag it, and the
  game's master volume applies on top of it.
- **Shanty4Heim Level-up Sound** - checkbox, on by default. The slider above sets
  how loud the jingle is.

The same settings live in `BepInEx/config/com.jonny.seashanty4heim.cfg` if you
would rather edit them there.
